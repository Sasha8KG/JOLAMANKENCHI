# «ЖОЛ АМАН КЕНЧИ» такси

Flutter-приложение такси для Сулюкты и Лейлекского района Баткенской области, Кыргызстан.

## Состояние исходников

Подготовлен исходный комплект **Stage 9**. Архив содержит Flutter-приложение, Firebase Android-конфигурацию, Cloudflare Worker и GitHub Actions workflow для облачной сборки Android debug APK.

## Возможности в исходниках

- Вход клиента через Firebase Email/Password.
- Публикация заказов в Firebase и Cloudflare Worker/D1.
- Выбор точки подачи на OpenStreetMap.
- Открытые заказы для одобренных водителей и автоматический выбор ближайшего откликнувшегося водителя в 10-секундном окне.
- Получение клиентом статуса заказа и GPS назначенного водителя.
- Диспетчерский вход через Firebase с серверной проверкой UID.
- Просмотр водителей и заказов, одобрение/отключение водителей, ручное назначение свободных заказов.
- Отмена клиентом до прибытия водителя.
- Отказ водителя от назначенного заказа до прибытия с возвратом заказа в общий список.
- Отметка водителем «Я прибыл»; после неё отмена и отказ блокируются сервером.
- Сводка количества заказов по статусам за текущий день.

## Важно

Это проект в разработке, не готовый коммерческий релиз. Worker Stage 9 из архива нужно отдельно развернуть и проверить на существующей D1-базе. APK ещё не собран и не проверен на телефоне. Серверный финансовый учёт завершённых поездок, загрузка фото документов/автомобиля, дорожная навигация с ETA и настоящая голосовая рация ещё не реализованы.

**Полный исходный комплект Stage 9 приложен в архиве, а не загружен в GitHub отдельными файлами.**
