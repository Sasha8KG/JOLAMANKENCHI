# «ЖОЛ АМАН КЕНЧИ» такси

Flutter-приложение такси для Сулюкты и Лейлекского района Баткенской области, Кыргызстан.

## Состояние исходников

Подготовлен комплект **Stage 14**. ZIP содержит Flutter-приложение, Firebase-конфигурацию, Cloudflare Worker, Storage Rules и workflow облачной сборки Android APK.

## Основные возможности в исходниках

- Клиент публикует заказ; одобренные водители видят открытые заказы.
- Автовыбор водителя учитывает свежесть GPS и 10-секундное окно откликов.
- Клиент видит статус заказа и GPS назначенного водителя.
- Диспетчер проверяется сервером по Firebase UID, одобряет водителей, назначает заказы и задаёт тарифы.
- Клиент отменяет заказ до прибытия; водитель может отказаться до прибытия с возвратом заказа в общий список.
- Фото удостоверения, водителя и автомобиля проходят ручную проверку диспетчером; отклонённый водитель может повторно подать документы.
- Диспетчер завершает поездку с фактической суммой; доступна дневная сводка.
- Stage 14 добавляет построение линии автомобильного маршрута от GPS водителя до точки подачи через OSRM demo service на данных OpenStreetMap. Клиент и водитель видят расстояние и приблизительное время в пути.

## Ограничения Stage 14

- Конечный адрес пассажир пока вводит текстом, координаты назначения не сохраняются; маршрут до конечного адреса не строится.
- Показана линия маршрута и общая оценка времени, но пошаговая голосовая навигация и turn-by-turn инструкции не реализованы.
- Публичный OSRM demo не гарантирует доступность, точность ETA или пригодность для коммерческой нагрузки. Для эксплуатации нужен собственный маршрутизатор или провайдер по договору.
- В маршрутизатор отправляются только координаты начала и конца, без имён, телефонов и ID заказа.
- Необходимо сохранять атрибуцию OpenStreetMap.
