# «ЖОЛ АМАН КЕНЧИ» такси

Flutter-приложение такси для Сулюкты и Лейлекского района Баткенской области, Кыргызстан.

## Состояние исходников

Подготовлен комплект **Stage 12**. ZIP содержит Flutter-приложение, Firebase Android-конфигурацию, Cloudflare Worker, приватные Storage Rules и workflow облачной сборки Android debug APK.

## Возможности в исходниках

- Клиент публикует заказ через Firebase и Cloudflare Worker/D1.
- Выбор точки подачи на OpenStreetMap; одобренные водители видят открытые заказы.
- Автоматический выбор водителя по свежему GPS и 10-секундному окну откликов.
- Клиент видит статус заказа и GPS назначенного водителя.
- Диспетчерский вход проверяется сервером по Firebase UID; диспетчер одобряет водителей и назначает заказы.
- Клиент отменяет заказ до прибытия; водитель может отказаться до прибытия с возвратом заказа в общий список.
- Фиксированные городские и междугородние тарифы настраиваются диспетчером.
- Диспетчер завершает поездку и учитывает фактическую оплату; дневной отчёт показывает поездки и сумму по водителям.
- В анкете водителя требуются фото удостоверения, фото водителя и фото автомобиля.
- Фотографии сохраняются в Firebase Storage по личному каталогу UID; Storage Rules разрешают чтение владельцу и диспетчеру.
- Диспетчерская панель получает ссылки на три документа для проверки перед одобрением водителя.

## Stage 12 — документы водителя

Worker создаёт отдельную таблицу D1 `driver_documents` и защищённый маршрут `POST /drivers/documents`. Существующие таблицы заказов и водителей не изменяются. Требуется вручную включить Firebase Storage и опубликовать правила из `backend/firebase-storage.rules`.

## Важно

Это проект в разработке, не готовый коммерческий релиз. Обновлённый Worker из архива нужно отдельно развернуть в Cloudflare. Node.js syntax check Worker, проверка скобок Dart и целостности ZIP выполнены. Flutter SDK/Dart analyzer отсутствует, поэтому `flutter pub get`, `flutter analyze`, APK-сборка и тест на телефоне не выполнены.

Проверка подлинности документов выполняется диспетчером вручную. Дорожная навигация с ETA и настоящая голосовая рация ещё не реализованы. Download URL Firebase содержит секретный токен — не распространяйте эти ссылки посторонним.
