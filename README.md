# «ЖОЛ АМАН КЕНЧИ» такси

Flutter-приложение такси для Сулюкты и Лейлекского района Баткенской области, Кыргызстан.

## Состояние исходников

Подготовлен исходный комплект **Stage 7**. В нём есть приложение Flutter, Firebase-конфигурация Android, Cloudflare Worker и GitHub Actions workflow для облачной сборки APK.

## Реализовано в исходниках

- Вход клиента через Firebase Email/Password.
- Создание заказа и отправка в Cloudflare Worker/D1.
- Выбор точки подачи на OpenStreetMap.
- Очередь открытых заказов для одобренных водителей.
- Отклик водителя и выбор ближайшего по актуальному GPS в 10-секундном окне.
- Получение клиентом статуса заказа и координат назначенного водителя.
- Защищённый API диспетчера: просмотр списка водителей и заказов, одобрение водителя и ручное назначение свободного заказа с защитой от повторного назначения.

## Важно

Это проект в разработке, не готовый коммерческий релиз. Stage 7 Worker ещё не развёрнут в Cloudflare и требует проверки на существующей D1-базе. Диспетчерский экран Flutter пока не подключён к новым API. APK ещё не собран и не проверен на телефоне. В исходном комплекте есть инструкция на русском языке.
