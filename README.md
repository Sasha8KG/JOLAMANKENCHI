# «ЖОЛ АМАН КЕНЧИ» такси

Flutter-приложение такси для Сулюкты и Лейлекского района Баткенской области, Кыргызстан.

## Состояние исходников

Подготовлен исходный комплект **Stage 8**. Архив содержит Flutter-приложение, Firebase Android-конфигурацию, Cloudflare Worker и GitHub Actions workflow для облачной сборки Android debug APK.

## Возможности в исходниках

- Вход клиента через Firebase Email/Password.
- Публикация заказов в Firebase и Cloudflare Worker/D1.
- Выбор точки подачи на OpenStreetMap.
- Очередь открытых заказов для одобренных водителей.
- Отклик водителя и выбор ближайшего по актуальному GPS в 10-секундном окне.
- Получение клиентом статуса заказа и GPS назначенного водителя.
- Диспетчерский вход через Firebase с серверной проверкой UID.
- Просмотр водителей и заказов, одобрение/отключение водителей, ручное назначение свободных заказов.
- Сводка количества заказов по статусам за текущий день.

## Важно

Это проект в разработке, не готовый коммерческий релиз. Worker Stage 7 должен быть отдельно развёрнут и проверен на существующей D1-базе. APK ещё не собран и не проверен на телефоне. Денежный учёт завершённых поездок, загрузка фото документов/автомобиля, дорожная навигация с ETA и настоящая голосовая рация ещё не реализованы. Полный исходный комплект Stage 8 предоставляется архивом.
