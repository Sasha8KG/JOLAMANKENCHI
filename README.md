# «ЖОЛ АМАН КЕНЧИ» такси

Flutter-приложение такси для Сулюкты и Лейлекского района Баткенской области, Кыргызстан.

## Состояние исходников

Подготовлен исходный комплект **Stage 10**. В архиве Stage 10 содержатся Flutter-приложение, Firebase Android-конфигурация, Cloudflare Worker и GitHub Actions workflow для облачной сборки Android debug APK.

## Возможности в исходниках

- Вход клиента через Firebase Email/Password и публикация заказа в Cloudflare Worker/D1.
- Выбор точки подачи на OpenStreetMap.
- Открытые заказы для одобренных водителей и автоматический выбор ближайшего откликнувшегося водителя в 10-секундном окне.
- Клиент видит статус заказа и GPS назначенного водителя.
- Диспетчерский вход через Firebase с серверной проверкой UID.
- Просмотр водителей и заказов, одобрение/отключение водителей, ручное назначение.
- Клиент может отменить заказ до прибытия водителя.
- Водитель может отказаться до прибытия; заказ возвращается в общий список для других водителей.
- Водитель отмечает прибытие; после этого отмена/отказ блокируются сервером.
- Диспетчер завершает поездку после отметки прибытия и вручную вносит фактическую сумму в сомах.
- Дневной отчёт показывает количество завершённых поездок и сумму внесённой оплаты по каждому водителю.

## Важно

Это проект в разработке, не готовый коммерческий релиз. Worker Stage 10 из архива нужно отдельно развернуть в Cloudflare и проверить на существующей D1-базе. При первом обращении Worker автоматически создаёт отдельную таблицу `trip_finances`, не меняя существующую схему `orders`.

APK ещё не собран и не проверен на телефоне. Сумма поездки вводится диспетчером вручную; автоматические тарифы, комиссия и расчёт чистой выплаты водителю ещё не реализованы. Также остаются незавершёнными загрузка фото документов/автомобиля, дорожная навигация с ETA и настоящая голосовая рация.
