# «ЖОЛ АМАН КЕНЧИ» такси

Flutter-приложение такси для Сулюкты и Лейлекского района Баткенской области, Кыргызстан.

## Текущий исходный комплект

Подготовлен **Stage 15**. ZIP содержит Flutter-приложение, Firebase-конфигурацию, Cloudflare Worker, Storage Rules и workflow облачной сборки Android APK.

## Основные функции

- Клиент создаёт заказ; одобренные водители видят открытые заказы.
- Автоматический выбор водителя учитывает свежесть GPS и 10-секундное окно откликов.
- Диспетчер проверяется сервером по Firebase UID, одобряет водителей, назначает заказы и настраивает тарифы.
- Проверка водительских документов: фото удостоверения, водителя и машины; диспетчер одобряет или отклоняет с причиной, водитель может подать документы повторно.
- Клиент отменяет заказ до прибытия; водитель может отказаться до прибытия с возвратом заказа в очередь.
- Диспетчер закрывает поездку с фактической суммой; доступна дневная сводка.
- Клиентская карта отображает актуальное GPS-положение назначенного автомобиля и точку подачи; водительское положение обновляется через сервер примерно каждые 5 секунд при активном заказе.
- Добавлена кнопка центрирования карты на автомобиле и предупреждение, если GPS не обновлялся более 60 секунд.
- Дорожный маршрут строится до точки подачи. Конечный адрес остаётся текстовым и уточняется пассажиром устно; водитель довозит пассажира по его указанию.

## Ограничения

- Для актуального положения водитель должен иметь интернет, разрешённую геолокацию и активное приложение. Фоновый GPS foreground service пока не реализован.
- OSRM demo — тестовый публичный маршрутизатор, не гарантирующий коммерческую доступность.
- Голосовая рация и голосовые пошаговые подсказки не реализованы.
- Это проект в разработке, не готовый коммерческий релиз.

## Проверки

Worker прошёл синтаксическую проверку Node.js; Dart-файл прошёл лёгкую проверку баланса разделителей; ZIP проверен на целостность. Flutter SDK отсутствует, поэтому flutter analyze, тесты, APK-сборка и проверка на телефоне не выполнены.
