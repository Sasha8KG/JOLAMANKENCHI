# «ЖОЛ АМАН КЕНЧИ» такси

Flutter-приложение такси для Сулюкты и Лейлекского района Баткенской области, Кыргызстан.

## Состояние исходников

Подготовлен комплект **Stage 13**. ZIP содержит Flutter-приложение, Firebase Android-конфигурацию, Cloudflare Worker, Firebase Storage Rules и workflow облачной сборки Android APK.

## Возможности в исходниках

- Клиент публикует заказ через Firebase и Cloudflare Worker/D1.
- Одобренные водители видят открытые заказы; выбор водителя учитывает свежесть GPS и 10-секундное окно откликов.
- Клиент видит статус заказа и GPS назначенного водителя.
- Диспетчерский вход проверяется сервером по Firebase UID; диспетчер одобряет водителей и назначает заказы.
- Клиент отменяет заказ до прибытия; водитель может отказаться до прибытия с возвратом заказа в общий список.
- Городские и междугородние тарифы настраиваются диспетчером.
- Диспетчер закрывает поездку и записывает фактическую оплату; доступна дневная сводка.
- Водитель отправляет фото удостоверения, своё фото и фото автомобиля.
- Диспетчер открывает документы внутри приложения, одобряет или отклоняет заявку с обязательной причиной.
- Отклонённый водитель может войти, увидеть причину и повторно отправить фотографии. При повторной подаче статус возвращается в ожидание, допуск отключается.
- Firebase Storage Rules ограничивают чтение владельцем и диспетчером, а загрузку — личной папкой владельца.

## Stage 13 — проверка документов

Worker автоматически добавляет в D1 поля статуса проверки, причины отказа, времени и UID проверившего, сохраняя существующие записи. Новые документы сохраняются как приватные Storage object paths; приложение загружает их для просмотра через Firebase SDK, без использования публичных download URL для новых заявок.

## Важно

Это проект в разработке, не готовый коммерческий релиз. Worker из архива нужно отдельно развернуть в Cloudflare, а правила из backend/firebase-storage.rules — вручную опубликовать в Firebase Console. Проверка node --check, миграция SQLite и целостность ZIP выполнены; Flutter SDK отсутствует, поэтому Flutter analyze, тесты, APK-сборка и проверка на телефоне не выполнялись.

Распознавание подлинности документов выполняет диспетчер вручную. Дорожная навигация с ETA и настоящая голосовая рация ещё не реализованы.
