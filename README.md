# «ЖОЛ АМАН КЕНЧИ» такси

Flutter-приложение такси для Сулюкты и Лейлекского района Баткенской области, Кыргызстан.

## Текущий исходный комплект

Подготовлен **Stage 16**. Полный комплект исходников, включая приложение и Cloudflare Worker, находится в ZIP-архиве Stage 16.

## Основные функции приложения

- Клиент создаёт заказ; одобренные водители видят открытые заказы.
- Автовыбор водителя учитывает свежесть GPS и 10-секундное окно откликов.
- Диспетчер проверяется сервером по Firebase UID, одобряет водителей, назначает заказы и настраивает тарифы.
- Фото удостоверения, водителя и автомобиля проверяются диспетчером; отклонённый водитель может повторно подать документы.
- Клиент отменяет заказ до прибытия; водитель может отказаться до прибытия с возвратом заказа в очередь.
- Диспетчер закрывает поездку с фактической суммой; доступна дневная сводка.
- Карта показывает GPS назначенного автомобиля и дорожный маршрут до точки подачи.
- Общая рация: живой групповой звук через LiveKit, push-to-talk при удержании кнопки и серверная аренда эфира для одного говорящего.
- Общий текстовый чат для диспетчера и одобренных водителей; ввод текста водителю отключается при активном назначенном заказе.

## Stage 16 — подключение связи

Голосовой канал требует создать LiveKit Cloud проект и задать в Cloudflare Worker переменные/секреты:
- LIVEKIT_URL
- LIVEKIT_API_KEY (секрет)
- LIVEKIT_API_SECRET (секрет)

API Secret остаётся только в Cloudflare Worker, Flutter-приложение получает краткоживущий JWT. Текстовый чат использует D1 Worker и сохраняет до 300 последних сообщений.

## Ограничения и проверки

Worker прошёл node --check; проверены SQL сценарии аренды эфира/чата, YAML pubspec, баланс разделителей Dart и целостность ZIP. Flutter SDK отсутствует, поэтому flutter pub get, flutter analyze, тесты, APK-сборка и проверка реального звука на телефонах не выполнены. Голос не заработает до подключения LiveKit и развертывания Worker. Проект пока не является готовым коммерческим релизом.

Полный исходный код Stage 16 находится в ZIP-архиве; в этом репозитории обновлён README, остальные файлы архива пока не опубликованы отдельными файлами.
