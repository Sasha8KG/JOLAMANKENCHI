# «ЖОЛ АМАН КЕНЧИ» такси

Flutter-приложение такси для Сулюкты и Лейлекского района Баткенской области, Кыргызстан.

## Текущий комплект — Stage 18

Stage 18 усиливает безопасность Android-релиза: release APK больше не может незаметно использовать debug-сертификат. Полный комплект приложения и Cloudflare Worker находится в архиве Stage 18; исходники Flutter пока не опубликованы в репозитории отдельными файлами.

## Функции проекта

- Заказ пассажира, точка подачи на карте, наличные/QR и фиксированные тарифы.
- Одобренные водители видят открытые заказы и могут принимать их самостоятельно.
- Автовыбор водителя учитывает свежесть GPS и 10-секундное окно откликов.
- Диспетчер одобряет водителей, назначает заказы, задаёт тарифы и смотрит дневную сводку.
- Клиент отменяет заказ, водитель отказывается до прибытия.
- Проверка водительских документов, фото водителя и автомобиля.
- GPS назначенного автомобиля и дорожный маршрут к точке подачи.
- Подготовлен общий голосовой канал LiveKit и текстовый чат.

## Stage 17 — автоматические проверки

Добавлены GitHub Actions, Codemagic и скрипт предварительной проверки. Preflight: 13/13. Синтаксис Worker и YAML проверены.

## Stage 18 — безопасная подпись

- Удалена возможность подписывать release APK отладочным debug-ключом.
- Release-сборка требует защищённые значения JAK_KEYSTORE_PATH, JAK_KEYSTORE_PASSWORD, JAK_KEY_ALIAS, JAK_KEY_PASSWORD.
- Ключи и пароли запрещено хранить в публичном репозитории или отправлять в чат.
- Подробная инструкция находится в ANDROID_RELEASE_SIGNING_RU.md.

## Ограничения

APK ещё не собран: Flutter SDK и облачная сборка не запускались. Голос LiveKit требует проекта LiveKit Cloud и секретов в Cloudflare Worker; Worker необходимо отдельно развернуть. Подписанный release APK нельзя выпускать до создания личного keystore владельца.

Полный комплект исходников Stage 18 передаётся архивом. В GitHub пока опубликованы документация, CI-конфигурация и отдельные настройки; полное дерево Flutter-приложения ещё не загружено.
