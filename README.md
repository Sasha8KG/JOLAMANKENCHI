# «ЖОЛ АМАН КЕНЧИ» такси

Flutter-приложение такси для Сулюкты и Лейлекского района Баткенской области, Кыргызстан.

## Состояние исходников

Подготовлен комплект **Stage 11**. ZIP-архив содержит Flutter-приложение, Firebase Android-конфигурацию, Cloudflare Worker и workflow облачной сборки Android debug APK.

## Возможности в исходниках

- Клиент публикует заказ через Firebase и Cloudflare Worker/D1.
- Выбор точки подачи на OpenStreetMap.
- Открытые заказы для одобренных водителей и автоматический выбор по свежему GPS и 10-секундному окну откликов.
- Клиент видит статус заказа и GPS назначенного водителя.
- Диспетчерский вход проверяется сервером по Firebase UID.
- Диспетчер просматривает водителей и заказы, одобряет водителей и вручную назначает заказы.
- Клиент отменяет заказ до прибытия; водитель может отказаться до прибытия, возвращая заказ в общий список.
- Водитель отмечает прибытие; после этого отмена/отказ блокируются.
- Диспетчер завершает поездку и учитывает фактическую оплату; дневной отчёт показывает поездки и сумму по водителям.
- Диспетчер задаёт отдельные фиксированные суммы для города и межгорода. Клиент видит тарифы; заказ не отправляется, пока цена выбранного тарифа не задана.

## Stage 11 — тарифы

Worker автоматически создаёт отдельную таблицу `tariff_settings`; существующая таблица `orders` не изменяется. Новые маршруты: авторизованный `GET /tariffs` и защищённый UID диспетчера `POST /tariffs`.

## Важно

Это проект в разработке, не готовый коммерческий релиз. Обновлённый Worker из архива Stage 11 нужно отдельно развернуть в Cloudflare и проверить. Node.js syntax check Worker и проверка SQL-таблицы тарифов выполнены. Flutter SDK/Dart analyzer отсутствует, поэтому flutter analyze, сборка APK и проверка на телефоне не выполнены.

Остаются незавершёнными загрузка фото документов/автомобиля, дорожная навигация с ETA и настоящая голосовая рация. Сумма завершённой поездки записывается диспетчером вручную с подстановкой настроенного тарифа.
