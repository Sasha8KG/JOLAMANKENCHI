# «ЖОЛ АМАН КЕНЧИ» такси

Flutter-приложение такси для Сулюкты и Лейлекского района Баткенской области, Кыргызстан.

## Текущий комплект — Stage 17

Подготовлен единый комплект Android-исходников для пассажира, водителя и диспетчера. Полный комплект Flutter/Android и Cloudflare Worker передаётся архивом `JAK_Android_Source_Stage17.zip`; на данный момент исходные файлы приложения ещё не загружены в этот репозиторий по отдельности.

## Основные функции

- Заказ пассажира, точка подачи на карте, наличные/QR и фиксированные тарифы.
- Одобренные диспетчером водители видят открытые заказы и могут самостоятельно принимать их.
- Автовыбор водителя учитывает свежесть GPS и 10-секундное окно откликов.
- Диспетчер одобряет водителей, назначает заказы, настраивает тарифы и видит дневную сводку.
- Клиент и водитель могут отменить/отклонить заказ до прибытия.
- Фото документов, водителя и автомобиля проверяются диспетчером.
- Карта показывает GPS назначенного автомобиля и маршрут до точки подачи.
- Подготовлен общий голосовой канал LiveKit с push-to-talk и текстовый чат диспетчера/водителей.

## Stage 17 — проверки и облачная сборка

Добавлены скрипт предварительной проверки конфигурации, проверка синтаксиса Worker, GitHub Actions и Codemagic workflow. Проверка конфигурации прошла: **13/13**. Синтаксис Worker и YAML-конфигурации прошли.

**APK пока не собран и не протестирован на телефоне.** Для этого исходники должны быть загружены в репозиторий, затем нужно запустить Android app verification во вкладке Actions и дождаться успешной сборки.

## Важные незавершённые подключения

- Голос LiveKit требует проекта LiveKit Cloud и секретов `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` в Cloudflare Worker.
- После изменения Worker его нужно отдельно развернуть в Cloudflare.
- Текущий workflow собирает debug APK для тестирования. Для распространения понадобится подписанная release-сборка и защищённый ключ подписи.
- Не помещайте LiveKit API Secret и ключ подписи Android в публичный GitHub или чат.

Проект пока не является готовым коммерческим релизом.
