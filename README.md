# «ЖОЛ АМАН КЕНЧИ» такси

Flutter-приложение такси для Сулюкты и Лейлекского района Баткенской области, Кыргызстан.

## Исходный комплект

Актуальный комплект исходников Stage 6 подготовлен отдельно в архиве `JAK_Android_Source_Stage6.zip`.

## Состояние Stage 6

- Клиентская регистрация и вход через Firebase Email/Password.
- Публикация заказов в Firebase и Cloudflare Worker/D1.
- Выбор точки подачи на OpenStreetMap.
- Очередь открытых заказов для одобренных водителей.
- Отклик водителя и выбор ближайшего по актуальному GPS в 10-секундном окне.
- Получение клиентом статуса заказа и GPS назначенного водителя.

## Важно

Это проект в разработке, не готовый коммерческий релиз. Worker-кандидат требует отдельного развёртывания и проверки на рабочей D1-базе. APK ещё не собран и не проверен на телефоне. См. `README_FINAL_RU.txt` в исходном архиве.
