# Подготовка подписанной Android-версии (Stage 18)

## Важно

Для тестов подходит debug APK. Для распространения пассажирам и водителям нужен release APK, подписанный личным Android-ключом владельца. Ключ должен храниться у владельца таксопарка в надёжном месте. Если потерять его, обновлять установленное приложение тем же способом может быть невозможно.

Не отправляйте файл ключа, пароли или API Secret в чат и не загружайте их в открытый GitHub. Сделайте резервную копию keystore на двух защищённых носителях.

## Что изменено

- Удалена опасная настройка, при которой release-сборка могла подписываться debug-ключом.
- Release-сборка останавливается, если отсутствуют четыре значения: JAK_KEYSTORE_PATH, JAK_KEYSTORE_PASSWORD, JAK_KEY_ALIAS, JAK_KEY_PASSWORD.
- В .gitignore добавлены key.properties, *.jks, *.keystore.
- Обычная debug-сборка не требует этих значений.

## Настройка в облаке позднее

1. На отдельном защищённом компьютере создать Android upload keystore.
2. Сохранить keystore и пароли в менеджере паролей и сделать резервную копию.
3. В выбранном CI добавить четыре защищённых секрета с указанными выше именами.
4. Передавать файл keystore в runner как защищённый файл/секрет; JAK_KEYSTORE_PATH должен указывать на временный путь этого файла.
5. Только после проверки секретов запускать release-сборку.

## Текущий статус

Ключ подписи ещё не создан и не добавлен в облако. Поэтому Stage 18 не выпускает подписанный APK. Это сделано намеренно: нельзя безопасно подписывать публичный релиз debug-ключом или выдуманным ключом.
