«ЖОЛ АМАН КЕНЧИ» такси — Stage 8

В этом этапе подключён экран диспетчера Flutter к реальному Cloudflare Worker API:
- загрузка списка водителей и последних заказов с сервера;
- одобрение и отключение допуска водителя;
- ручное назначение свободного заказа одобренному водителю;
- защита от повторного назначения выполняется сервером;
- сводка количества заказов за сегодня по статусам;
- обновление данных вручную и жестом обновления.

ВАЖНО:
1. Для открытия панели нужен действующий Firebase-сеанс именно диспетчера с UID, прописанным в Worker. Вход в панели теперь запрашивает телефон и пароль Firebase; старый локальный ПИН-код не используется.
2. Worker Stage 7/8 должен быть развёрнут в Cloudflare. В этой сборке Worker не менялся; используются его маршруты /dispatcher/overview, /drivers/approve и /orders/assign.
3. APK не собран и не проверен: в доступной среде нет Flutter/Dart SDK. Проверка исходников вручную не заменяет flutter analyze/build.
4. Экран заработка пока показывает только количество заказов по статусам. Денежные суммы не выдумываются и не считаются по локальным тестовым данным. Завершение поездок, серверная цена и заработок водителя — следующий этап.
5. Фото водительского удостоверения/автомобиля, дорожная навигация с ETA и настоящая голосовая рация ещё не подключены.
